E the original v5 prototype's live-activity grammar, driven by real deltas — no pulses anywhere: create = outline "sketch" that fills (v5 added-node → merge beat) · update = connections fire once, synapse-style, and the halo lifts then drains (~3.5s, v5's colorAmount decay — a state, not an oscillation) · remove = fill drains to outline, sketch fades · residue = v5 frameHeat (border +0.15·intensity, ~5.5s decay) · attribution = v5 presence pills vertically centered on the node (agent-colored fill + provider glyph; the user is base-white). No hue swaps — amber = stale, red = blocked.   A grow-in / amber pulse / red fade — fast settle, low residue.   B frame tints in its layer hue + draining freshness bar + actor badge (who).   D a soft specular shimmer sweeps across the changed frame + a glint on the dot — elegant, quiet, no color shift.   C ripple fires along edges — most alive, needs rate-limiting.
